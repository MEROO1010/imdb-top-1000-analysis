# IMDb Top 1000 Movies and TV Shows Analysis

## Overview
This project analyzes the **IMDb Top 1000 Movies and TV Shows dataset** to uncover trends, patterns, and insights. The analysis includes data cleaning, exploratory data analysis (EDA), and interactive visualizations.

## Dataset
- **Source**: [Kaggle - IMDb Top 1000 Movies and TV Shows](https://www.kaggle.com/datasets/harshitshankhdhar/imdb-dataset-of-top-1000-movies-and-tv-shows)
- **Features**: Title, Year, Genre, Rating, Votes, Director, Actors, etc.

## Project Structure
- `data/`: Contains the raw and cleaned datasets.
- `notebooks/`: Jupyter Notebook with the full analysis.
- `visualizations/`: Saved plots and charts.
- `requirements.txt`: Python dependencies.

## How to Run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Open the Jupyter Notebook: `jupyter notebook notebooks/imdb_analysis.ipynb`
